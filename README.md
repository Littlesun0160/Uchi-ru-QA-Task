Выполненная работа
-------------------

1. Исправлены ошибки в существующих тестах
2. Добавлен новый автотест 

"Проверка открытия статьи через поиск" - `opens article from search`

Выполняет следующую последовательность шагов:
- Открыть виджет поддержки
- Ввести название статьи в поиск
- Проверить, что статья есть в результатах
- Открыть её
- Проверить, что заголовок открытой статьи соответствует ожидаемому
